# mdlook 离线桌面版待办清单

目标：把 macOS App 打造成一个离线优先的 Markdown 写作、公众号排版和复制发布工具。默认不依赖登录、云同步、分享链接、计费或在线 AI。

## 产品原则

- 本地文件优先：用户可以直接打开、编辑、保存 `.md` 文件和文件夹。
- 复制发布优先：所有能力围绕“写好 Markdown，排成公众号样式，一键复制”展开。
- 离线可用：无网络时仍可写作、预览、换主题、导出和保存。
- 少账户心智：隐藏登录、云同步、分享、计费等在线产品入口。

## 通用核心能力（网页端 + 桌面端）

这些功能两端都适合做。网页端通常保存到浏览器本地存储，桌面端可以进一步映射到真实文件。

- [x] 自动保存：编辑内容自动保存到本地存储。
- [x] 主题管理：内置主题和自定义 CSS 主题。
- [x] 模板库：保存和管理常用 Markdown 模板。
- [x] 最近文章：记录最近编辑的文章或草稿。
- [x] 未保存状态提示：展示“已保存 / 有修改 / 保存失败”等状态。
- [x] 发布前检查：检查本地图片、空链接、公众号不支持的锚点、超宽表格、标题层级异常。
- [x] 导出 HTML：离线导出带内联样式的公众号 HTML 文件。
- [x] 导出 PDF / 长图：用于存档或非公众号渠道分享。
- [x] 查找替换：支持全文查找、替换、大小写选项。
- [x] 文章大纲：按标题生成大纲并支持跳转。

## 桌面端专属能力

这些功能依赖真实文件系统或 macOS 原生能力，优先只在 Tauri 桌面端展示。

- [x] 本地文件打开：支持系统对话框选择 `.md` / `.markdown` 文件。
- [x] 本地文件夹工作区：支持打开文件夹并展示 Markdown 文件树。
- [x] 保存回源文件：当前编辑内容可写回原始本地文件。
- [x] 最近文件：记录最近打开的 Markdown 文件，可从桌面侧边栏快速打开。
- [x] 另存为：未绑定本地文件的内容可保存为新的 `.md` 文件。
- [x] 自动保存到源文件：本地文件编辑后自动写回磁盘。
- [x] 源文件保存状态提示：侧边栏展示当前文件是否有未保存变更。
- [x] 本地图片 assets 管理：拖入图片后复制到文章同级 `assets/` 目录，并改写为相对路径。
- [x] 最近工作区：记录最近打开的文件夹。
- [x] 应用启动恢复：启动时恢复上次文件夹和当前文件。
- [x] 文件外部变更检测：本地文件被其它编辑器修改时提示重新加载。
- [x] 快捷键：打开文件、打开文件夹、保存、另存为、复制到公众号、切换预览。
- [x] macOS 菜单栏：提供文件、编辑、视图等原生命令入口。
- [x] macOS 导出菜单：提供 Markdown、HTML、PDF、长图等原生命令入口。

## 内容资产

- [x] 本地模板库：内置产品说明、技术文章、通知公告、活动推文、周报等模板。
- [x] 模板导入导出：模板保存在本地，可备份和迁移。
- [x] 本地历史版本：保存最近 N 次内容快照，可回滚。
- [x] 主题导入导出：离线导入 / 导出 CSS 主题。
- [x] 主题预览样张：切换主题时展示同一篇样张的实际效果。

## 默认隐藏或移除

- [x] 登录 / 账户中心入口。
- [x] 云同步入口。
- [x] 分享链接入口。
- [x] 计费 / 赞赏入口。
- [x] 在线 AI 入口。
- [x] 在线主题仓库依赖。
