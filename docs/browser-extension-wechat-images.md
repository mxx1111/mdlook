# 浏览器扩展与公众号图片配置

mdlook 浏览器扩展可以在微信公众号后台打开侧边栏，并使用已配置的公众号能力处理文章图片。

## 1. 开启公众号开发能力

登录[微信公众平台](https://mp.weixin.qq.com)，进入「设置与开发」，开启开发者能力并获取 AppID 与 AppSecret。密钥只应保存在你信任的设备和服务中，不要粘贴到公开 Issue、聊天记录或截图里。

## 2. 配置服务器 IP 白名单

在微信公众平台的开发设置中，将实际调用微信接口的后端公网 IP 加入白名单。这里应填写服务器出口 IP，不是浏览器或 Mac 的局域网 IP。

## 3. 在 mdlook 中保存配置

打开「图片上传」中的微信公众号配置，填入 AppID 与 AppSecret 后保存。正式使用前先用一篇不含敏感信息的测试文章验证图片转换。

## 4. 在公众号后台使用扩展

打开微信公众号图文编辑页面，通过浏览器扩展菜单进入 mdlook 侧边栏。完成排版和图片处理后，再复制或写入公众号编辑器。

如果图片转换失败，请依次检查：

- AppID 与 AppSecret 是否属于同一个公众号；
- 后端公网 IP 是否已加入白名单；
- 自建能力后端是否可以访问微信接口；
- 图片是否为公网可访问的 JPG、PNG、GIF 或 WebP。

mdlook 不会要求你把公众号密钥提交到公开仓库。反馈问题时请删除或遮盖所有密钥。
